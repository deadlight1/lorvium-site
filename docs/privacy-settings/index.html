Privacy promise

Kids Todo App is designed around data minimization, child safety, parent control, and clear choices. The goal is to keep family routines useful without asking for more information than the app needs.

This page explains the privacy controls intended for parents and guardians. Final details will be checked against the released app before publication.

Privacy controls

Privacy-sensitive choices should stay in parent-managed areas of the app.

Child profile information
Parents can edit or remove a child profile when profile controls are available in the app.
Task and routine data
Parents can manage tasks, rewards, progress, and history used for family routines.
Notifications
Parents can enable or disable reminders so notifications match the family's needs.
Analytics
If analytics are needed, they should be privacy-conscious, non-personal, and used only to understand app performance and reliability.
Marketing
Children should not receive targeted advertising or marketing messages through Kids Todo App. If the release includes ads in the free version, ad-free use is planned for premium and final details will be documented before publication.
Data sharing
Family data should not be sold. If service providers are needed, sharing should be limited to what is needed for app operation, support, security, or delivery, with final details documented before release.
Account deletion
Parents can request deletion of family or account data when account features are available.
Data export
Parents can request a copy of family data if export is supported by the release. Export details will be documented before publication.

Children's privacy

Kids Todo App should not collect unnecessary personal information from children. Children should not be asked to make privacy-sensitive choices on their own.

The app should not sell children's data. Parent involvement should be required for account, profile, deletion, export, and other privacy-sensitive actions.

Parent rights

Parents and guardians can contact Lorvium about privacy questions and family data requests.

  • Review family data
  • Correct inaccurate information
  • Delete child data
  • Withdraw consent where applicable
  • Contact support about privacy

Security

Kids Todo App should use secure storage for family data, limited access to operational systems, encryption where applicable, and regular review of privacy practices.

Security decisions should be reviewed as the app moves toward release so public privacy statements match the real product.
