Overview

Shortcut Hub Studio is a local Windows utility that helps you find installed apps, detect existing desktop shortcuts, and create missing shortcuts in one action.

This policy explains how Shortcut Hub Studio handles data when used on your device.

Data collected by the app

Shortcut Hub Studio is designed to work locally on your Windows device. Lorvium does not receive personal data from the app.

The app does not require a user account and does not include analytics, advertising, tracking, social SDKs, or a server-side user account system.

Data stored locally

Shortcut Hub Studio may read local app and shortcut information needed to show installed apps, detect existing desktop shortcuts, and create missing shortcuts requested by the user.

This information is used on the device for app functionality and is not sent to Lorvium or third parties.

How data is used

Local app and shortcut information is used only to display the dashboard, identify shortcut status, and perform shortcut creation actions selected by the user.

Data sharing

Shortcut Hub Studio does not sell, rent, or share user data with advertisers, analytics providers, data brokers, or other third parties.

Third-party services

Shortcut Hub Studio does not use third-party analytics, advertising, tracking, or cloud account services.

Data retention and deletion

Any local settings or app state created by Shortcut Hub Studio remain on your device unless you change settings, clear local app data, or uninstall the app.

Uninstalling the app removes its local app data according to normal Windows app behavior.

Security

Shortcut Hub Studio follows a data-minimization approach by using local information only for the utility features requested by the user.

Children

Shortcut Hub Studio is not directed specifically to children and does not include ads, tracking, social features, or user accounts.

Changes to this policy

This Privacy Policy may be updated if the app functionality changes or if legal or platform requirements change.
